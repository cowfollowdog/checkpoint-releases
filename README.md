# Checkpoint

A checkout desk for a classroom equipment room. Scan the gear, scan the badge, and the room
knows who has what — on one Mac, with no account to make and no server to run.

**[Download →](https://github.com/cowfollowdog/checkpoint-releases/releases/latest)**

## Installing

1. Open the downloaded `.dmg`.
2. Drag **Checkpoint** onto the **Applications** folder beside it.
3. Open it from Applications.

Drag it across rather than running it from the mounted disk image — macOS runs apps launched
from a disk image out of a temporary read-only location, which breaks things quietly.

The app is signed and notarized, so it opens with a double-click. It works offline.

## Requirements

- macOS 26 or later.
- Apple silicon or Intel.
- Any barcode scanner that types what it reads.

## Your records

They stay on this Mac. Nothing is uploaded, and there is no account. Updating never touches
them, and the app takes a backup on its own before any change to the data format.

## Updating

Quit Checkpoint, open the new `.dmg`, drag it across, and choose **Replace**. The app does
not check for updates — watch this page if you want to know a version exists.

## Problems

Open an [issue](https://github.com/cowfollowdog/checkpoint-releases/issues). What you
scanned, what you expected, and what happened instead is usually enough.
